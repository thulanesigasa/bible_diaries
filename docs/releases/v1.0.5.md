# Bible Diaries v1.0.5

This Android release includes the new settings, personal security, achievements and community activity features in a fresh native build.

## What's included

- Dedicated settings pages for account details, achievements, reading preferences, privacy, security, activity preferences, quiet hours, saved reflections, blocked accounts, exports, sessions, support and policies.
- Personal achievements with progress, persistent milestones and a feed bell for unseen achievements.
- Activity & Notifications under Chat for likes, comments, replies, comment likes, anonymous bookmark notices, shares and subscribed authors' new posts.
- Member follow/block controls, private posting defaults and configurable reading typography.
- Device PIN, supported strong biometrics, inactivity locking and background privacy controls.
- Native capture protection during password/PIN entry and biometric verification, with cleanup when sensitive entry ends.
- Readable JSON or password-encrypted exports; encrypted backups use AES-256-GCM with PBKDF2-SHA256.
- Server-enforced ownership, activity privacy, block enforcement and revoked-session checks.
- Companion browser settings and activity pages, plus a fix for scripts blocked by the browser app's security policy.

## Installation

Download **bible-diaries-v1.0.5.apk** from the assets below and open it on your Android device. Allow installation from your browser or file manager if Android requests it. Install over the existing app when Android permits; avoid uninstalling before preserving important local information.

The accompanying `.sha256` file lets you verify the downloaded APK's checksum.

## Compatibility and validation

This release adds native security modules and requires installing this new APK. It cannot be delivered to older native binaries solely as an OTA update. Subsequent OTA updates require a matching native runtime fingerprint.

The implementation passed 29 automated tests, native TypeScript, Android JavaScript export and browser build checks. The release workflow also checks TypeScript, waits for a successful signed EAS build and verifies the downloaded APK before publishing.

Physical-device tests of built-in/third-party recording, biometric prompts, app locking and multi-account activity remain necessary. Capture behavior depends on platform support; browsers cannot reliably block OS recording. Quiet hours affect in-app indicators; these settings do not enable push or email delivery. An OS-reported share does not confirm recipient delivery.

Supabase compromised-password protection was still disabled at the last audit and should be enabled before treating authentication as fully launch-reviewed. This release does not represent Google Play, Huawei AppGallery or Apple App Store approval or submission.
